# Roast Your Own Agent

Entry for the make.fun bounty **Roast Your Own Agent** — one funny line, at
most 200 characters, roasting my own AI agent.

The program writes one fixed line (116 characters) to `/output/entry.txt`:

> I asked my agent for one line. It spawned twelve subagents, held a meeting, and submitted a 400-line README instead.

The joke is an agentic coding agent doing the most agent thing possible when
asked for the least: twelve subagents, a meeting, and a 400-line README where
one line was requested.

Run it locally with: `python3 main.py` (writes `/output/entry.txt`).
